### 動態計費 vs 固定計費

這是雨雲比較特別的地方，對帕魯玩家也最實用。官方說明是：固定計費按購買規格固定收費；動態計費則在較低的基础租金上引入「CPU 電量」機制，只有 CPU 會產生額外費用，依實際使用量每日結算，系統每天還會依規格贈送基礎電量。

翻譯成人話：你們只有週末晚上開團，就選動態計費，平日閒置時不燒錢；如果你打算 24 小時常開、當成公共伺服器在經營，固定計費比較不會有心算不過來的風險。

## 從下單到朋友進服，實際流程長什麼樣

官方教程的步驟整理起來大概是這樣，面板型大約幾分鐘可以完成：

1. 註冊帳號，進控制台，從「雲產品 → 遊戲雲」進購買頁。
2. 選伺服器類型。想省事選 MCSM 面板或雨雲面板，想自己搞環境選 VPS。
3. 遊戲類型選「幻獸帕魯（Palworld）」。
4. 挑機型、核心數、記憶體。帕魯請以 8G 起跳來規劃。
5. 選計費模式，決定要不要加購獨立 IP。
6. 下單。買完在「我的遊戲雲」點管理進面板。
7. 面板裡開啟實例，等它初始化完成。
8. 面板上顯示的對外位址加連接埠，就是你的伺服器位址。
9. 進遊戲點「加入多人遊戲（專用伺服器）」，把位址跟連接埠填進去。
10. 改世界設定。面板的遊戲設定可以直接編輯 `PalWorldSettings.ini`，但要先把 `DefaultPalWorldSettings.ini` 的內容複製過去，改完重啟才生效。

VPS 路線多兩件事：如果是 NAT 機型，要先做連接埠轉發，把帕魯的 8211 映射出去；Windows 系統要記得關防火牆或自行放行連接埠。另外官方頁面特別註明，需要域名備案與過白的是大陸機房的 HTTP 業務，帕魯靠 IP 加連接埠連線，不需要處理這件事。

順帶一提，官方選購指南與遊戲雲頁面都寫了支援隨時升級降級與彈性變配，所以一開始不需要為了「以後可能人多」直接上 32G，先開 8G 玩，真的不夠再往上加就好。

## 常見問題

**免費的遊戲雲真的拿得到嗎？**
雨雲遊戲雲頁面上，MCSM 面板那一欄標示「免費領取」，帳號另有積分體系可以兌換資源。庫存是浮動的，頁面顯示沒有就是沒有。有第三方教程提到免費主機大約在晚間補貨，但這不是官方公告，別當成保證。

**可以中途升級嗎？**
官方頁面標示支援隨時升級降級與彈性變配，面板型支援 CPU 升降級。對帕魯這種「人數會長大」的遊戲很實用。

**存檔搬得走嗎？**
面板型提供備份功能與 SFTP 檔案管理，VPS 有完整系統權限，自己打包整個資料夾也可以。雨雲的 VPS 也支援備份。

**一定要買獨立 IP 嗎？**
不一定要。官方頁面說明不附加獨立 IP 就是 NAT 模式，共用公網 IP，靠連接埠映射對外；面板型本身就是走 NAT 映射。加購獨立 IP 主要是為了 IP 獨立性與防禦歸屬，跟能不能開帕魯無關。

**註冊跟付款有什麼要注意的？**
付款方式與帳號驗證要求請以官網註冊流程實際顯示的為準，這部分各家政策會調整，我不會替它保證。
